# Региональные цены

Цена хранится отдельно для сочетания проекта, комплектации и региона. Поддерживаются `nn` (Нижний Новгород) и `msk` (Москва), как в техническом хедере сайта. Валюта — рубли, значение — положительное целое число.

Наборы комплектаций: панельно-каркасные — `start`, `standard`, `project`; модульные — `standard`, `project`, `turnkey`. `start` не участвует в ипотеке. Неизвестная региональная цена не заменяется ценой другого региона.

Краткое описание, состав, подарки и подробные разделы редактируются в CMS → Блоки → Комплектации. У блока два варианта: «Панельно-каркасные дома» и «Модульные дома». Сайт автоматически выбирает вариант по технологии проекта. Изменения применяются ко всем проектам соответствующей технологии. В карточке проекта есть просмотр и ссылка на редактор общего блока. Начальные тексты перенесены из `src/lib/catalog/tiers.ts`; прежние копии внутри проектов сохранены в скрытых полях для совместимости и не определяют содержимое страницы. Проект и регион определяют только цену.

В редакторе блока сначала выбирают технологию, затем одну комплектацию. Пункты и разделы подписаны своим содержимым и изначально свёрнуты. Рядом работает общий компонент предпросмотра страниц: четыре устройства, масштаб, обновление и полноэкранный режим. Он отображает несохранённые изменения через настоящий компонент сайта; цены в этом просмотре не подставляются. Публикация общих изменений происходит после сохранения блока.

В CMS → Каталог доступен импорт CSV/JSON с проверкой перед загрузкой и ссылка на коллекцию «Прайс». CSV UTF-8:

```csv
projectSlug;configuration;region;price
barnhouse-113;standard;nn;5750000
barnhouse-113;standard;msk;6200000
```

Эти значения служат примером формата, а не утверждённым прайсом. JSON использует те же поля:

```json
{"rows":[{"projectSlug":"barnhouse-113","configuration":"standard","region":"nn","price":5750000}],"dryRun":true}
```

API: `POST /api/project-prices/import`, `Content-Type: application/json`. Авторизация — JWT действующего сотрудника с ролью super-admin, admin или editor (`Authorization: JWT <token>`). В режиме `dryRun:true` изменения не записываются. Без dryRun импорт обновляет существующие цены и создаёт отсутствующие. Проекты ищутся по текущему адресу или исходному `catalog:<slug>`; дубли, включая разные адреса одного проекта, отклоняются. Все строки применяются в одной транзакции, ошибки откатывают весь импорт.

Нужные строки можно импортировать частями: другие цены остаются прежними. До 5000 строк за запрос. Ответ: `{validated, updated, dryRun}`. Старое поле цены комплектации относится только к NN и используется, пока для NN нет отдельной строки прайса. Для Москвы автоматического переноса нет.
