- До исправления новый сайт передавал только roistat_visit; CMS включала в комментарий сообщение и URL, игнорируя остальные meta.

## Исправление

Рекламные параметры входной страницы сохраняются в first-party HttpOnly cookie на сессию браузера. При новой размеченной кампании старые параметры заменяются. При передаче заявки сервер добавляет UTM, yclid, gclid, _ym_uid и roistat_visit из разрешённых параметров/cookie. CMS включает данные в уже сопоставленное поле comment и отдаёт рекламные параметры отдельными верхнеуровневыми полями вебхука. Параметры формы из meta также включаются в комментарий. Пустые рекламные параметры не выдумываются. Данные появляются у новых обращений после публикации; история автоматически не переписывается.
