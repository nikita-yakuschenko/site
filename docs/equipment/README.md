## Как читать

Обычная выемка текста не работает: в немецкой версии буквы вшиты
картинками-глифами без юникодной таблицы (`pdftotext` выдаёт кашу), у скана
текстового слоя нет. Нужен OCR — `tesseract` с русским и немецким языками
плюс рендер страниц в изображения (`pdftoppm` из poppler; в системе сейчас
есть только `pdftotext`).

Встроенные изображения при этом достаются без OCR, через `pypdf`:

```bash
python -c "import pypdf; r=pypdf.PdfReader('docs/equipment/wen_wbz150_de.pdf'); [open(f'out_{i}.jpg','wb').write(im.data) for i,im in enumerate(r.pages[1].images)]"
```
