# Страница /stories

Локальная реализация концепта `AVGST.zip` (19 октября 2026).

Основания: [ADS 1.1](https://tracker.avgst.ru/articles/ITD-A-3),
[AES 1.1](https://tracker.avgst.ru/articles/ITD-A-2),
[AMS 1.3](https://tracker.avgst.ru/articles/ITD-A-1), правила `AGENTS.md`.

## Контент и поведение

- Видео, обложки, цитата, площади и сведения о владельцах переиспользуются из `src/lib/copy.ts`.
- Шкала годов — с 2026 по 2014 слева направо, как на `/about`. Пустые серые, доступные — фирменный иссиня-чёрный, выбранный — жёлтый с обводкой. По умолчанию открыт ближайший год с историями. В одном году сначала до 3 историй, дальше кнопка «Показать больше историй». Переключение года фильтрует ленту и не скроллит; прямая ссылка `#story-…` открывает нужную запись.
- На десктопе слева видео, справа плашка: заголовок → описание → мета с иконками → блок проекта. На мобилке: заголовок, описание и мета сверху, затем видео, затем карточка проекта.
- Миниатюра проекта: при совпадении имени в CMS — ссылка на карточку в каталоге. Если карточки нет (индивидуальный или снят с производства) — жёлтая пометка как «Скоро» в ипотечном калькуляторе; ссылка ведёт в модульные проекты или на `/business`.
- У каждой истории постоянный якорь `#story-…` для прямых ссылок.
- Сохранены SiteChrome, YandexRating, VideoLightbox, согласия на внешние embed и существующий Radix/shadcn Select. Новых зависимостей и изменений схемы CMS нет.
- Hero использует общий PageHero в варианте cutout, как на странице бизнеса: та же геометрия, описание, кнопка и иллюстрация. Изображение предоставлено владельцем: public/img/pages/storieshero.png; кнопка плавно прокручивает к ленте через scrollIntoView без якорной ссылки и изменения URL (с учётом prefers-reduced-motion). Рейтинг находится справа под шапкой, в ряду хлебных крошек.
- Блоки содержимого используют CMSContentBlock со стабильными ключами PageHero, StoriesEntry-*, StoriesNextStep; содержимое PageHero привязано к маршруту /stories.
- Стили страницы изолированы в CSS Module, используют токены проекта. Заголовки наследуют `.section h1/h2`; декоративные надзаголовки исключены. Жёлтый используется только для главного действия заключительного блока.

## Проверка

`e2e/stories.spec.ts` проверяет фильтры и годы, прямые ссылки, согласия перед
загрузкой видео, Escape и возврат фокуса. Ширины: 1440, 390, 320 px; проверяются
переполнение и размер заголовков.

Скриншоты создаются в `output/stories/`. Рейтинг в автоматических тестах
фиксирован ответом API; на рабочей странице используется живой YandexRating.

Typecheck, production build и lint изменённых файлов проходят. Общий lint
блокируют существующие ошибки `@next/next/no-assign-module-variable` в
`scripts/index-site.mjs:69,91`; этот скрипт в рамках страницы не менялся.

Коммита, push и деплоя в этой работе нет. Чужие локальные изменения сохранены.

Создать карточку AV4 через MCP YouTrack не удалось: первая попытка завершилась
тайм-аутом 300 секунд, вторая — ошибкой соединения с tracker.avgst.ru/mcp.
После первой попытки поиск подтвердил отсутствие карточки; идентификатор задачи
не получен. Учёт этой работы в трекере остаётся незавершённым.
