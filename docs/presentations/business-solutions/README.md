# Бизнес-презентация Авангард Строй

14 слайдов, 16:9. Исходные сведения взяты из страницы `/business` в этом проекте. Производственные изображения и логотипы оригинальные. Палитра и шрифт соответствуют сайту: `#0b1020`, `#fcc90c`, `#f5f6f8`, Geist Sans. Заголовки 30 px, без декоративных надзаголовков.

## Сборка

Из корня проекта:

```powershell
python -m pip install -r docs/presentations/business-solutions/requirements.txt
python -m playwright install chromium
python docs/presentations/business-solutions/build.py
```

Сценарий повторяет механику [catalog](https://github.com/nikita-yakuschenko/catalog): структурированные данные → Jinja2 HTML → Playwright/Chromium PDF с фиксированными страницами, печатными фонами, нулевыми полями и `prefer_css_page_size=True`.

- `content.json` — редактируемая информация, источники и исходные данные расчётной модели.
- `presentation.html.j2` — структура слайдов.
- `presentation.css` — фирменная вёрстка.
- `build.py` — встраивание ресурсов, расчёты, экспорт и проверки.

Результат в `output/pdf/business-solutions/`: автономная HTML-страница со встроенными шрифтом и изображениями, PDF, превью каждой страницы итогового PDF, контактный лист, JSON-отчёт проверок и список источников. Для пересборки нужны оригинальные изображения из `public` и шрифт пакета `geist` в `node_modules`; готовый HTML работает автономно.

Числа по срокам, доходу, нагрузке и команде — иллюстративная модель сайта. Они сопровождаются пояснениями на слайдах. ФОТ воспроизводит алгоритм `src/lib/business-payroll.ts`; он не включает оплату строительных бригад, бэкофис, отдельный расчёт налогов и страховых взносов. Скрытые на странице блоки отраслей и контрактного производства не включены отдельными разделами. Слайд первого проекта сформулирован как предложение начать обсуждение, а не как обещание условий договора.

Автоматический preflight проверяет число страниц, формат 16:9, загрузку ресурсов и шрифта, границы и пересечения текста, область колонтитула, извлечение текста, шрифты и ссылки PDF. Финальная визуальная проверка выполняется по растрированным страницам PDF. Превью HTML дополнительно сохранены для сопоставления.
