# Перенос панельно-каркасных проектов в каркасные — 26.10.2026

На продакшене обработано 27 исходных проектов. Создано 17 каркасных копий, использованы 10 уже созданных вручную. Каркасные записи опубликованы по исходным адресам; исходные записи сохранили ID и код, получили `pkd-` и сняты с публикации. Для Камелота 101 восстановлена правильная принадлежность технологий исходной записи и копии.

Контент всех 27 пар совпал после исключения технологии, адреса, идентификаторов, публикации и статистики. На каждую копию приходится 14 совпадающих региональных цен, включая историю.

Восстановлены счётчики десяти обнулённых исходников: 946 просмотров, 2 лайка и 4 шера, вместе с ключами голосования. Источник — резервная копия CMS `cms-191ea5be66161bfa0f5fe5026d61b585876c65e3-20261026T140217Z.dump`, 26 октября 17:02:17 МСК. События между этой копией и обнулением не восстановлены: в версиях карточек эти данные отсутствовали.

Исправлено сохранение: код и счётчики читаются из основной строки PostgreSQL под блокировкой в транзакции сохранения. Устаревшая редакторская версия больше не затирает актуальную статистику. Поле `unpublishedAt` сохраняет отдельное состояние «Снят с публикации» в таблице, фильтре и карточке; служебный статус Payload остаётся draft, чтобы запись была недоступна на публичном сайте. Новые копии начинаются с нулевых счётчиков и новым кодом.

Скрипт `cms/scripts/migrate-panel-to-frame.ts` по умолчанию показывает план. `--apply` выполняет перенос в одной транзакции, повторный запуск использует существующие пары. Перед применением сделана локальная резервная копия таблиц проектов, версий и цен; перед релизом также сохранён штатный полный дамп CMS. Эти файлы не включены в Git.

Проверка: 136 тестов CMS, TypeScript, ESLint, проверки схемы и интеграционные тесты релиза прошли. Все 27 публичных адресов вернули страницы с каркасной технологией; выборочные архивные адреса показывают страницу отсутствующего проекта после обновления кэша.
