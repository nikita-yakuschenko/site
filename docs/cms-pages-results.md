# Проверка редактора страниц

Дата: 18 октября 2026. Исходный индекс: 26 записей `/pages`, 132 размещения, 62 определения блоков.

## Проверено локально

- Сняты текущие тексты, ссылки и изображения всех маршрутов; ошибки рендера отсутствуют. Исходные значения: `cms/data/page-content-baseline.json`.
- 166 проверок сохранения и публичного отображения для 85 действующих записей блоков: успешно. Проверяются представители каждого имеющегося типа поля, а не каждая строка текста отдельно. Первичный прогон содержал 178 проверок; 12 проверок четырёх удалённых дублирующих редакторов подборок исключены из текущей матрицы.
- 163 проверки выбора блока в изолированном превью: успешно. Готовый дом требует опубликованной записи такого типа, которой в локальной базе нет.
- Реальное открытие текстового поля в CMS → сохранение → проверка на странице: успешно.
- Реальная пакетная загрузка через существующий загрузчик → сохранение → добавление фотографий в галерею: успешно. Замена изображений и порядок проверены также в просмотрщике фотографий.
- Тестовые правки восстановлены; тестовые загруженные файлы удалены.
- 69 тестов CMS, TypeScript обоих приложений и обе производственные сборки: успешно. Добавлены проверки зависимости счётчиков от текущего каталога и запрета замены вычисляемой подписи сохранённым текстом.
- ESLint сайта: 0 ошибок, 27 предупреждений. В изменённых существующих компонентах CMS остаются прежние 11 ошибок и 7 предупреждений: результат совпадает с проверкой тех же файлов из HEAD до изменений.

## Ограничение по запросу

Две сложные секвенции производства обозначены в структуре; их кадры не подключены к редактированию. Вычисляемые значения каталога и ипотечных расчётов продолжают использовать свои исходные редакторы и расчёты.

## Производственная проверка

Рабочий индекс обновлён: 26 страниц, 160 размещений блоков. Русские названия и состав проверены для каждого размещения; пустых составов вне оговорённого исключения производства нет.

159 изолированных превью проверены на опубликованном сайте без ошибок. Шесть записей являются переадресациями. Превью готового дома условное: в базе нет опубликованного экземпляра этого типа; используется существующий редактор проектов.

Все 20 неперенаправляющих маршрутов открываются без ошибок JavaScript; шесть переадресаций зафиксированы отдельно. На `/about` проверены ширины 1440 и 390 px: переполнений и сломанных загруженных изображений нет.

«Подборки» используют исходный редактор выбора серии и обложки. Счётчики получаются из каталога, не представлены редактируемыми строками: панельные — 26, барнхаусы — 16, классика — 22, модульные — 20. Значения сверены с API каталога, содержащим 46 записей. Все четыре обложки восстановлены в исходных полях и загружаются на сайте. Дата дня открытых дверей также сохраняет свой источник данных.

Повторное заполнение CMS не создало новых записей и сохранило контрольную сумму всех 2702 частей блоков, включая значения и порядок. Тестовых маркеров в рабочей базе нет. Перед заполнением создана резервная копия базы на сервере.

Сайт и CMS выпущены; новые запуски GitHub Actions, задачи и настроенные этапы имеют русские названия. Ошибка серверной сборки Unbounded устранена подключением того же шрифта локальным файлом с лицензией.

Машинные отчёты: `cms-page-preview-production-check.json`, `cms-page-render-production-check.json`, `cms-series-database-check.json`, `cms-content-initialization-check.json`. Локальные тесты сохранения намеренно запрещают адрес production.
